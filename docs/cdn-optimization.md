# 国内网页 CDN 解析优化

## v1.1.0 · 2026-10-28

### 为什么要扩充清单

国内分流版只对清单内的域名使用阿里 DoH；清单外的国内网站会走默认的 Cloudflare DoH（经代理）。Cloudflare 不知道你的真实网络位置，常把国内服务解析到境外或远端节点，网页明显变慢，个别站点直接连不上。

本次挑选了 50 个常用国内站点（主站或主要静态资源主机）做对照：同一时间分别用 Cloudflare DoH（经代理，与插件默认路径相同）和阿里 DoH（`https://223.5.5.5/dns-query`）解析，再从本机物理网卡直连各自返回的前两个地址，记录 TCP 连接加 TLS 握手的最短耗时。其中 8 个已在原清单内（7 个由 `*.cn` 覆盖，另有 `alicdn.com`），不重复添加。其余 42 个站点的结果：

| 结果 | 数量 | 例子（Cloudflare → 阿里） |
| --- | --- | --- |
| 阿里明显更快 | 24 | 北大法宝 186 → 46 ms；知网 kns 1911 → 113 ms；360 搜索 1661 → 123 ms；酷狗 769 → 47 ms；银联 574 → 44 ms |
| Cloudflare 返回地址不可连 | 1 | 斗鱼：Cloudflare 地址连接失败，阿里 30 ms |
| 两者相近（多为同一组源站地址） | 16 | CSDN、博客园、Gitee、豆瓣、58 同城等 |
| 无法判断 | 1 | `weibocdn.com` 裸域名本身不提供 HTTPS，两边都连不上；作为微博资源域名加入 |

这 42 个站点对应 41 个注册域名，按“根域名 + 子域名”加入清单，共 82 条映射。两者相近的服务也一并加入：它们是国内服务，查询不必经过代理。

结果受网络、CDN 调度与缓存影响，是本次网络环境下的一次对照，不代表所有环境的固定速度。新增项只改变 DNS 查询服务器，不添加业务 DIRECT 规则。

### 加密 DNS 端点必须保持 IP 写法

同一网络中，带域名 SNI 的 DoH 请求（`dns.alidns.com`、`doh.pub`）TCP 能连上但 TLS 握手超时，而直接用 IP 的写法（`https://223.5.5.5/dns-query`，不带 SNI）30–130 ms 内正常返回。部分网络会按 SNI 拦截公共 DoH，插件继续只使用 IP 端点；自行添加加密 DNS 时也应优先使用 IP 写法。

### 单个 CDN 节点故障：不要用 `server:system` 或 Cloudflare 兜底

本次还遇到 `s1.hdslb.com`（B 站网页脚本）在阿里 DoH 下多轮都只返回一个地址 `112.16.250.35`，该节点从本网络连接超时，导致 B 站首页卡住；同一网络的运营商 DNS 也会间歇返回这个地址。对照了几种处理：

| 做法 | 结果 | 结论 |
| --- | --- | --- |
| `server:system`（系统/运营商 DNS） | 多数时候能拿到可用节点 | 明文 DNS，**破坏防泄漏目标**；且同样会间歇返回故障节点 |
| `server:https://1.1.1.1/dns-query`（Cloudflare 经代理） | 返回境外节点，可连接，但 1.6 MB 脚本耗时 35–41 s | 加密但太慢，不适合大文件 |
| 腾讯 DNSPod DoH | 解析失败率高，也会返回同网段地址 | 不作为替代 |
| 别名到同一 CDN 的兄弟主机：`s1.hdslb.com = i0.hdslb.com` | `i0` 经阿里 DoH 解析出的节点可正常提供 `s1` 内容，约 0.2 s | 仍走阿里加密 DNS，**推荐的本地例外** |

别名例外依赖两台主机共用同一 CDN，属于针对具体网络的本地处理，不写入公共插件。添加前应确认兄弟主机的节点能返回目标主机的内容（同一路径、带目标 SNI 请求成功）；CDN 恢复后删除。

## v1.0.2 · 2026-10-28

国内分流版原有列表覆盖了抖音主站与视频域名，但遗漏了部分网页脚本、静态资源与直播资源。启用全局 Cloudflare 代理解析后，这些遗漏主机可能得到境外 CDN 地址，再命中原配置的兜底代理。

本次仅新增以下精确主机名的 `server:https://223.5.5.5/dns-query` 映射：

- `lf-c-flwb.bytetos.com`
- `lf3-webcast.bytetos.com`
- `lf-cdn-tos.bytescm.com`
- `lf-security.bytegoofy.com`
- `lf-douyin-pc-web.douyinstatic.com`
- `lf-normal-gr-sourcecdn.bytegecko.com`

这些主机均在抖音网页实际加载中出现，并完成了阿里与 Cloudflare 的加密 DNS 结果对照。部分关键脚本经阿里返回地址访问更快；结果受网络、CDN 调度和缓存影响，不代表所有环境的固定速度。

没有扩大到共享 CDN 的整个域名后缀，没有固定 CDN IP，也没有新增强制直连业务规则。原有 DNS 端点、端口防护、HTTPDNS 插件、策略组和业务分流继续保留。

## B 站图片部分加载失败

`bilibili.com`、`hdslb.com`、`bilivideo.com` 等已在国内解析列表内。若只有某个图片主机反复超时，应结合仪表中的 HostMap、实际分流和连接日志检查具体 CDN 地址，不能仅因页面慢就替换全局 DNS。

在本次网络中，`i2.hdslb.com` 的国内 CDN 地址连接超时，另一条加密解析路径返回的地址可访问。因此仅在该设备主配置中添加以下临时例外；它没有写入公共插件：

```ini
[Host]
i2.hdslb.com = server:https://1.1.1.1/dns-query
```

这条例外继续使用已有的 Cloudflare 代理加密 DNS，业务访问仍由原分流决定，可能使用代理并消耗代理流量。其他 B 站域名继续使用阿里 DoH。不同网络不应照搬；国内 CDN 恢复后可删除本地例外。

> v1.1.0 补充：后续对照发现 Cloudflare 给 B 站静态资源返回的是境外节点，大文件明显变慢（见上方 v1.1.0 的单节点故障对照）。优先改用同一 CDN 兄弟主机的别名例外，并确认可用后再替换。

## 更新与回滚

在 Loon 中更新国内分流版插件后，核对新增主机名的 HostMap 和 DNS 记录。若旧 DNS 或连接仍被复用，可重新连接 Loon 并刷新网页。

回滚公共插件可使用上一提交的文件；回滚本地 B 站例外只需在 Host 映射中移除对应主机名（如 `i2.hdslb.com`、`s1.hdslb.com`），不要恢复或覆盖整份配置。
