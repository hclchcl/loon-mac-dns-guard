# 制作检查记录与待测范围

日期：2026-10-28（Asia/Shanghai）

## 已完成的制作检查

- 本机 Loon 版本已读取：0.5.0（Build 1009），应用最低 macOS 版本为 13.0。
- 查阅 Loon 官方插件、DNS、主配置、Host 映射与规则文档，按插件允许的字段编写。`hijack-dns` 留在主配置补充说明中，没有写入插件 General。
- 标准版包含 13 条规则、12 条 Host 映射；国内分流版包含相同 13 条规则和 237 条 Host 映射，其中 225 条为国内解析匹配项。
- 在停止测试的要求提出前，已对下面 4 个端点各发送一次 `example.com` 的 A 和 AAAA DNS wire-format POST，共 8 项。均返回 HTTP 200、`application/dns-message`、匹配的查询 ID 与有效 DNS 响应，且未跳过 TLS 证书验证。

| 端点 | A | AAAA |
| --- | --- | --- |
| `https://1.1.1.1/dns-query` | 有效响应 | 有效响应 |
| `https://1.0.0.1/dns-query` | 有效响应 | 有效响应 |
| `https://223.5.5.5/dns-query` | 有效响应 | 有效响应 |
| `https://223.6.6.6/dns-query` | 有效响应 | 有效响应 |

这些请求只说明端点当时可以通过本机当前网络访问，不能证明本插件中的规则或 DNS 出口已生效。
