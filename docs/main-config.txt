# 合并说明，不是完整配置。请先备份，切勿整段替换现有文件。

# 1. 在现有 [General] 下合并，同名键只保留一行：
[General]
hijack-dns = *:53

# 2. Loon → 配置 → DNS 服务器：
# 查询回落 = 关闭
# DoH 流量模式 = Rule
# 包含系统 DNS 地址：可关闭则关闭；若不能关闭，保留并检查实际查询记录。
# 插件的 PROXY = 已有的可用境外代理策略，不能选择 DIRECT 或直连回退组。
# PROXY 只承载 DNS 查询，不决定网页走哪个地区，应选延迟最低的地区，
# 不必与网页出口相同。清单外的域名首次访问都要等这一轮查询。
# 作者实测（2026-11-04）：经香港组约 42 ms/次，经日本约 100 ms，
# 经美国家宽约 180 ms；Loon 仪表中的实际解析由 0.4–2 s 降到多数 0.05–0.25 s。
# 最好绑定只含该地区节点的 url-test/fallback 组，单个手动节点失效时
# 默认解析会随之中断（查询回落已关闭）。示例（“香港节点”换成你已有的
# 节点筛选或节点名；在 [Proxy Group] 中新增，再把插件 PROXY 选为它）：
# DNS 出口 = url-test,香港节点,interval = 600,tolerance = 50
# DNS 查询流量很小，组内是否含倍率节点基本不影响用量。

# 3. 检查所有全局 DNS 来源。
# doh-server/dns-server 是追加项，插件不能清除主配置/其他插件中的服务器。
# 从主配置和其他插件移除不需要的全局 DoH/DoQ/DoH3；不要把阿里与
# Cloudflare 放在同一个全局并发列表，否则不能保证国内/国外解析分流。
# 检查已有 [Host]、SSID DNS 与订阅的 [Host]/[DNS]，不能只看插件内容。

# 4. 服务器地址使用域名的节点：
# 对每个现有节点或 [Remote Proxy] 订阅行追加/修改这一参数：
# server-dns="https://223.6.6.6/dns-query,https://223.5.5.5/dns-query"
# 保留原订阅地址、鉴权及其他参数；不要把实际订阅内容提交到公开仓库。
# 多个 server-dns 并发查询、取最先返回的结果，单个端点被拦不会拖慢；
# 但命中后失败不会回到全局 DNS，所以至少保留两个直连端点。
# 不建议再加 DNSPod IP 端点：作者网络中约 1.3 s，永远抢不到首个结果。
# 实测 Loon 0.5.0 (1011) 在 TTL 未过期时也会重复解析节点域名，
# 每次新建代理连接都要等这次查询，因此端点必须直连且低延迟，不要经代理。
# 使用 IP 端点和正常 TLS 证书校验，不需要先解析 DNS 服务器的域名。
# 这是建立代理前的直连加密引导解析，解析器能看到节点服务器域名。
# 如果对应节点域名已匹配 [Host] 中的指定 DNS/映射，Host 的优先级更高，
# 应先核对并修正这个具体条目；不能假定添加 server-dns 就一定生效。
# 不支持 server-dns 的旧版请升级或为具体节点域名建立加密 DNS Host 映射。
# 不要对所有域名设置 server:system，也不要额外开启普通 DNS 回落。

# 5. 使用 TUN 接管，核对系统 DNS 的 IPv4/IPv6 地址是否确实进入 Loon。
# 已被 bypass-tun、进程绕过或其他 VPN 接走的流量不受插件端口规则保护。
# 不盲目移除整个局域网绕过列表，以免损坏内网业务。
# 如需将某个实际系统 DNS 的 IPv4 地址单独纳入 TUN，Build 1007+ 支持
# include-tun 的 /32 路由；应按当前地址精确配置并检查与绕过路由的优先级。
# include-tun 不支持 IPv6，IPv6 DNS 的接管需单独检查。

# 6. 重连后看 DNS 与请求记录；本地规则优先于插件规则。
# UDP DNS 应被接管或拒绝；拒绝不等于透明代答成功。
# 两个插件版本只启用一个；回滚时按备份恢复你修改过的条目和 App 开关。
# 在 Loon Dashboard → DNS 记录 可逐条看到解析服务器与耗时，这是判断
# 出口与速度最直接的依据；更换 PROXY 绑定不需要断开 Loon。

# 7. 影响网页打开速度的主配置项（插件无法代为设置）：
# Loon 先给系统返回 Fake IP，只有命中需要 IP 的规则或走 DIRECT 时才真正解析。
# 自写的 IP-CIDR/IP-ASN 规则带上 no-resolve，GEOIP 放在规则末尾，
# 让按域名就能分流的请求不必先等 DNS。远程规则集内容以其作者为准。
# 若自行添加 doq-server，插件的 DEST-PORT 784/853 REJECT 会拦截这些查询。
# Loon 自身的联网检测（internet-test-url）不使用 Host 映射，走全局 DNS；
# 检测显示偏慢不代表网页解析慢，以 DNS 记录中的实际请求为准。
