# Mac 应用与网页广告过滤器

导入地址：

```text
https://raw.githubusercontent.com/hclchcl/loon-mac-dns-guard/main/plugins/Loon-Mac-Ad-Filter.plugin
```

面向 Loon for Mac 0.5.0（1009）编写。包含 20 条专用广告域名规则、15 条按路径处理广告的原生复写、34 个精确 MitM 域名，无外部脚本。

## 与原插件的关系

本机“可莉广告过滤器”展示的是 24 条规则、82 条复写。本文件参考其“按具体服务处理广告”的方向，使用其他公开规则选择并重新组织；没有复制、解密或完整移植这 82 条复写。不能把本文件的数量或服务名单当成与原版等效的证明。

## HTTPS 复写的前提

1. 域名规则不需要 MitM，可先单独使用这部分。
2. 若要处理 HTTPS 路径，你需要在 Mac Loon 的域名与证书设置中启用 MitM，并安装、信任自己设备生成的 Loon CA。
3. 插件只追加列出的 34 个精确域名，采用 `request if … then …` 原生语法，不需要脚本运行权限或外部脚本下载。
4. 不要关闭上游 TLS 证书校验。证书固定、自定义加密或未被 Loon 解密的请求，不能保证路径规则生效；出现连接错误时应移除相应 MitM 域名或停用此插件。

本项目没有操作你的证书或修改现有 MitM 设置。没有把全部 `*.qq.com`、`*.baidu.com` 或所有流量纳入解密。

## 收窄与省略

所选规则来自 blackmatrix7 的公开来源快照，保留选中原文及修改后的表达式。对网易云音乐等规则做了收窄，没有照搬同时阻断 AB 测试、搜索或配置的宽泛规则；对共享 API 增加完整域名及路径边界。没有改变会员、账号、支付、升级或下载权限。

没有编造 JSON 响应结构，也没有添加未经材料支持的字段删除规则。因此，同域信息流广告、混合响应、视频贴片、浏览器页面占位等不在全面去除的承诺范围内。逐条原文、修改后正则、动作与 MitM 主机见 [rewrite-selection.json](../sources/rewrite-selection.json)。

导入后关闭原可莉广告过滤器，再启用本插件；保留原文件便于回滚。本次未进行实际导入、证书解密、应用联网或去广告效果测试。
