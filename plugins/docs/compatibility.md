## 本次适配

- 三个新文件分别声明 `macOS`，不沿用可能排除 Mac 0.x 版本的 iOS 3.x 最低版本字段；具体运行要求仍以各文件所用语法及实际导入结果为准。
- 网络规则使用 Loon 原生域名及逻辑规则；复写采用官方文档中的原生 `request if … then …` 语法。
- HTTPDNS 的 Surge 专属字段未带入，IP 阻断限于常见 HTTP(S) 端口；明文路径复写不增加证书要求。
- 广告平台只使用选中域名和平台关键词，没有加入广告 IP 大列表及主业务域名整体阻断。
- 应用与网页过滤只选取有来源的广告路径，精确列出需要 MitM 的主机，没有完整复刻原插件所有 iOS 功能。
- 没有修改当前正在使用的插件开关、DNS、代理策略、主配置或证书；原有 DNS 文件不会因本次新增文件而被覆盖。

## 由用户进行的测试

遵照用户要求，本次未进行 Loon 导入/启用、请求触发、广告效果、DNS 回落、证书解密、重连、冷启动、IPv6、抓包或其他实机测试。没有对源规则中的地址进行探测。

用户自行导入后，可以分别核对插件解析情况、规则/复写命中、正常登录与下载、聊天和播放、证书固定报错及需要保留的内网业务。出现问题时逐个停用新插件，以保留的原插件恢复使用。

配置数量、来源可访问和发布链接存在，都不能代替上述运行结果。
